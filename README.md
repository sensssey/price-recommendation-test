# Тестовое задание ТОЛЬКООПТ

Исправленная функция расчёта рекомендованной цены по ценам конкурентов и тесты к ней.

`starter.py` содержит функцию `recommend_price` и пример из условия, `test_starter.py` содержит тесты.

Нужен Python 3.10+, сторонних пакетов нет.

```
python starter.py
python -m unittest -v
```
